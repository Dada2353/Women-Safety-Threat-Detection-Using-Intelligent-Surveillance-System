About the Project

This educational prototype uses a general-purpose pretrained YOLOv8 model to recognize objects. It does not identify harassment, violence, distress, or weapons reliably. A separately collected, ethically sourced, validated dataset and extensive evaluation would be needed for any specialized safety application.
